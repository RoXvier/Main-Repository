APKEditor 1.4.9
https://github.com/REAndroid/APKEditor/releases/tag/V1.4.9

java -Xmx1900m -jar APKEditor-1.4.9.jar b -t xml -i enhanced-8 -o ColorBlendr-Enhanced-unsigned.apk -no-cache

The signing key is stored encrypted. With the passphrase in a file (never commit it):

openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in signing/colorblendr-enhanced.jks.enc -out signing/colorblendr-enhanced.jks -pass file:<passphrase file>

signing/*.jks is in .gitignore.

uber-apk-signer 1.3.0 (aligns, then signs)
https://github.com/patrickfav/uber-apk-signer/releases/tag/v1.3.0

java -jar uber-apk-signer-1.3.0.jar -a ColorBlendr-Enhanced-unsigned.apk --ks signing/colorblendr-enhanced.jks --ksAlias colorblendr-enhanced --ksPass colorblendr --ksKeyPass colorblendr -o out

Builds signed with signing/colorblendr-enhanced.jks install over 3.1.3-enhanced.7 and .8. Builds up to .6 were signed with a key that is not in this archive, so .8 does not install over them.


StockWallpaperColors (only when its Java source changes)

dex2jar 2.4, for d2j-dex2jar.sh and lib/dx-30.0.2.jar
https://github.com/pxb1988/dex2jar/releases/tag/v2.4

cd stock-wallpaper
d2j-dex2jar.sh --force -o app.jar <any enhanced APK>
APP_JAR=app.jar ./build.sh
DX_JAR=<dex2jar>/lib/dx-30.0.2.jar APKEDITOR_JAR=<APKEditor-1.4.9.jar> BASE_APK=<any enhanced APK> ./dexify.sh

build.sh compiles the helper against the app's own classes. dexify.sh turns the result into smali and prints a directory; copy
<that directory>/classes/com/drdisagree/colorblendr/utils/wallpaper/StockWallpaperColors.smali
over the file of the same name in enhanced-8/smali/classes18/com/drdisagree/colorblendr/utils/wallpaper/, then rebuild and sign as above.

integrate.py is how enhanced-8 was made from a copy of enhanced-6 (the project in the .6 source archive): it applies the smali and version changes listed in README.md.

python3 integrate.py <pristine enhanced-6> <copy of enhanced-6 to turn into enhanced-8> <directory printed by dexify.sh>


Checking against the official code (no device needed)

kotlin-compiler 2.3.0
https://github.com/JetBrains/kotlin/releases/tag/v2.3.0

cd stock-wallpaper
APP_JAR=app.jar ./build.sh
d2j-dex2jar.sh --force -o final.jar <the APK to check>
APP_JAR=app.jar KOTLIN_HOME=<unpacked kotlinc directory> UPSTREAM_KT=../upstream-v3.1.3/app/src/main/java/com/drdisagree/colorblendr/utils/wallpaper/WallpaperColorUtil.kt ./difftest.sh checked=final.jar

difftest.sh compiles the official WallpaperColorUtil.kt, then runs it, the helper, and the WallpaperColorUtil packaged in each "label=jar" through the device states in difftest/test/Scenarios.kt and compares the returned colours (and, for the helper, every framework call). It finishes with the seed chosen after a change, on Samsung and off it. Expected for .8: 0 scenarios return different colours.
